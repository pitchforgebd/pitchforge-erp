# Glossary

| Term                                 | Meaning                                                                                          |
| ------------------------------------ | ------------------------------------------------------------------------------------------------ |
| Accrual basis                        | Income and cost are recorded when earned or incurred, not when cash moves                        |
| AIT / TDS                            | Advance income tax / tax deducted at source on payments                                          |
| VDS                                  | VAT deducted at source by the paying party                                                       |
| BIN                                  | Business Identification Number for VAT                                                           |
| Mushak                               | Bangladesh VAT forms (e.g. Mushak 6.3 VAT invoice)                                               |
| Control account                      | A ledger account (AR, AP, payroll payable) that only the posting engine writes to                |
| Dimension                            | A tag on a journal line (project, department, employee, partner, vendor) used for reporting      |
| Posting                              | Turning an approved document into a balanced journal entry                                       |
| Posting engine                       | The single service that writes the ledger                                                        |
| Reversal                             | A new entry that cancels a posted entry and links to it                                          |
| Period lock                          | A closed month that accepts no new entries without an approved reopen                            |
| Capital / Current / Due from partner | A partner's invested money / allocated profit less drawings / money the partner owes the company |
| Profit distribution run              | The journal that allocates undistributed profit to partners after the reserve                    |
| GRN                                  | Goods received note                                                                              |
| Three-way match                      | Bill checked against the purchase order and goods receipt before payment                         |
| ESS                                  | Employee self-service                                                                            |
| Contract (API)                       | The Zod schema and OpenAPI definition both frontend and backend must follow                      |
| Mock API                             | A Mock Service Worker server that answers the contracts with sample data during Phase 1          |
| Outbox                               | A table written in the same transaction as a business change, from which events are published    |
| SoD                                  | Segregation of duties                                                                            |
| ADR                                  | Architecture decision record                                                                     |
